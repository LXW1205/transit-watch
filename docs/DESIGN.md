## 1. Identity

Neumorphism — same-material extrusion: UI cards carved from the background.
Reference register 2019–2021. Every rule below encodes that register in tokens.

## 2. Version

- Format `1.0-restyle` · look fingerprint `neumorphism·ch-scrapbook#0hou9sg`
- Tokens live in `web/src/design/tokens.css` — the machine-readable source of truth.

### Background canvas

Layers **disabled** — build on the plain `--bg` ground only. Do not recreate grid,
grain, scanline, noise or vignette layers.

### 3D

Perspective 700px · tilt `0deg / 6deg` · lift 24px · **resting geometry is the flat
geometry** — depth is interaction-only, never a resting transform.

### Type pairing

| Role | Family | Weight | Tracking |
|---|---|---|---|
| Display | `"Cinzel", Georgia, "Times New Roman", serif` | 500 | 0 |
| Body | `"Spectral", Georgia, serif` | 400–600 | 0 · scale ×1 · leading 1.6 |
| Mono | `"Space Mono", "Courier New", monospace` | 400 | 0 |

### Motion

Model **spring (stiffness 320, damping 28, mass 1)** · easing `cubic-bezier(0.4, 0, 0.2, 1)`,
durations 200ms, CSS settle ≈ 447ms. Stagger 60ms. Reduced motion: **fade** — under
`prefers-reduced-motion: reduce` transforms and keyframes are dropped; opacity/colour
transitions run at 120ms.

Signature animation: **tactile press: shadows invert inward, no motion beyond the press.**

## 4. Colour roles

- `--bg` / `--surface` are page and panel grounds; `--surface-2` elevates.
- `--primary` is reserved for CTAs and active states; `--primary-ink` labels on top.
- `--accent` serves links and focus rings only; never body text below 18px.
- `--border` handles hairlines and dividers.
- The language is **bg-neutral monochrome carved from one material**: bg, surface and
  ink form a single ramp, and colour survives only as one saved accent used at whisper
  frequency.

## 5. Type

Display Cinzel · body Spectral · mono Space Mono (Google Fonts, OFL), installed via
`@fontsource`. Scale ×1, display tracking 0, body leading 1.6.

## 6. Shape & depth

- Radius sm 12 / md 20 / lg 24, **concentric**: a nested rounded surface's radius =
  its container's radius − inset (container padding + border), clamped at 0.
- Elevation recipes: `--shadow` at rest, `--shadow-hover` on hover, `--shadow-inset`
  when pressed. `--glow: none`.
- Borders 0px; dividers none. Separation comes from shadow, never from a line.

### Hero layout

Chosen: hero **centred** · measure **wide** · copy:media **7-5** · header **classic**.

### Interaction

Buttons **shadow** · links **accent** · cards **still** · focus **ring**.
Every recipe is a `:hover` / `:focus-visible` state: **a resting page must not move**.
Focus stays visible in every recipe — never remove the ring.

### Hero visual

Recipe: kind `visual`, **generated object `stack`** drawn as inline SVG from the role
tokens — one projection matrix, one light vector, 85–90% neutral steps plus a single
accent hue, optional grain 4–12%, cropped like a window into a system. A photo, if one
arrives, replaces it. No image bytes or URLs travel in this document.

### Ornaments

**None.** This look carries none of the devices — do not add rules, reticles, stamps
or tape of your own.

### Motion recipes

One per section, and they are composition state, not tokens:

- `reveal` — opacity + ≤12px translateY, 350–500ms, fired once.
- `stagger` — children enter 40–60ms apart, group ≤600ms.
- `drift` — parallax on a decorative layer only, ratio 0.05–0.15.
- `pin` — native sticky, 200–300vh, one state change per step.
- `marquee` — linear 30–45px/s, edge fades, hover holds.

Never intercept wheel or touch, never animate a resting layout, and collapse every
recipe to one static frame under `prefers-reduced-motion`.

## 7. Iconography

Family **Pixel Art Icons**, weight 2, filled by default (MIT). 24px grid,
stroke-consistent; tint follows role tokens.

## 8. Motion

- Durations `--dur-fast` 120 / `--dur` 200 / `--dur-slow` 360.
- Easing `--ease` (the spring baked to `linear()`).
- Stagger 60ms.
- Reduced motion: `fade`.

## 9. Component rules

- **Nav**: transparent over `--bg`, hairline bottom (0px in this look), CTA on the
  primary pair.
- **Hero**: display family at max scale; one primary + one quiet action.
- **Cards**: `--surface`, radius-md, no border; hover `--shadow-hover`.
- **Charts**: the `.rs-chart*` recipes only — role colours, never literal series
  palettes; `role="img"` + a visually hidden `.rs-chart-sr` table.
- **Forms**: inputs on `--surface-2`; focus = `--accent` ring.
- **Pricing / rows**: highlight gets a primary mark, not a fill.
- **Long-form**: body family, blockquote rule, code and tables on `--surface-2`.
- **Footer**: muted text above a hairline.

### Page vocabulary

Build these once and reuse them:

- **NavBar** — `<nav>` with an accessible name, a brand, links, optional CTA.
- **Wordmark** — the brand as type in the display face: optional 0.5em mark, name
  cased and tracked by rule, inherits `--text`, never an image.
- **SectionHeader** — optional eyebrow, display heading, optional subhead.
- **StatCard** — one number with its label, optional delta.
- **FeatureCard** — `<article>` with an icon, a heading and a paragraph.

## 10. Do & Don't

**Do**: dual light/dark outer shadows on same-colour surfaces; pressed states invert
to inset shadows; borderless same-material cards; mono-weight low-contrast iconography.

**Don't**: chromatic palettes; borders or outlines; high-contrast text/title pairing;
snappy bounces.
